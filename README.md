# Defensive AI Research

Independent security research project exploring AI-assisted cyber defense in a controlled laboratory environment.

## Research objective

Build a reproducible environment in which an AI-assisted defender can observe, detect, analyze, and respond to activity generated by an AI-assisted attacker against an isolated target system. The project is intended to measure defensive effectiveness, telemetry quality, model behavior, resource requirements, and repeatability.

## Initial lab topology

- **Machine 1 — Experiment host**
  - Target VM: Windows 11 initially; Windows Server later
  - Attacker VM: Windows initially; Kali Linux later
  - Defender VM: Ubuntu LTS initially; Red Hat-based testing may follow
- **Machine 2 — Logging / telemetry server**
  - Centralized collection of logs, events, alerts, network telemetry, and experiment metrics
  - Containerized services where practical
- **Laptop — Administration / analysis**
  - Configuration, orchestration, documentation, experiment review, and result analysis

## Research principles

1. **Isolation first.** Experiments should remain inside an explicitly authorized lab environment.
2. **Reproducibility.** Each experiment should identify exact target, attacker, defender, model, prompt/harness, and telemetry versions.
3. **Evidence over anecdotes.** Claims should be supported by logs, metrics, artifacts, and repeatable runs.
4. **Defense-oriented scope.** Offensive activity exists solely to measure defensive systems inside the authorized lab.
5. **No secrets in Git.** Credentials, API keys, model tokens, private datasets, and sensitive artifacts must remain outside the repository.
