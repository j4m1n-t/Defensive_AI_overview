# Defender Environment

Configuration, detections, automation, and model/harness documentation for the AI-assisted defender.

## Initial sequence

1. Ubuntu LTS defender VM
2. Local-model integration through Ollama after hardware benchmarking
3. Red Hat-based defender comparison after the initial methodology is stable

The defender should be evaluated on observable outcomes such as detection coverage, response latency, false positives, action quality, resource use, and repeatability.
