# Documentation

Project documentation should separate design decisions, methodology, and evidence-backed findings.

## Planned sections

- `architecture/` — lab topology, trust boundaries, network design, and data flow
- `methodology/` — experimental controls, evaluation criteria, and repeatability procedures
- `decisions/` — architecture decision records and major tool/model selections
- `findings/` — validated observations derived from completed experiments

Research claims should point back to experiment IDs and preserved evidence wherever possible.
